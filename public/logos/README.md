# Logos

Any image here can be referenced by its file name (without extension) from
`src/content/about.ts`. `.png`, `.svg`, `.webp` and `.jpg` all work, in any
letter case. If a referenced logo is missing, the site shows a tidy monogram
instead — so you can add files later (e.g. `bits_logo.png`, `apple.png`,
`studio.png`) and they appear on the next build.
